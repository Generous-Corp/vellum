# Import and reimport

The installed DesignIR backend connects the public Python `vellum` CLI to
`@vellum/design-ir`. This experimental lane accepts JSON in any of these
contracts:

- a credential-free Pulp Figma plugin JSON export with format
  `2026.05-figma-plugin-v1`, parser `0.1.0`, and compatibility schema `0.3`,
  containing one audio-free root frame;
- a Vellum adapter source model containing `source`, `root`, optional `tokens`,
  `assets`, and `diagnostics` fields;
- canonical `https://vellum.dev/schemas/design-ir/v1` JSON.

The `--source-type figma` route decodes that pinned JSON envelope directly.
The current Pulp emitter's audio-free node vocabulary is exactly `frame`,
`text`, `ellipse`, `image`, and `vector`. The `frame` and `text` node kinds map
directly into the retained native tree, while unsupported fields on either are
still preserved and diagnosed. `ellipse` lowers explicitly to a rounded view;
`image` and `vector` remain inspectable but carry hard conversion-loss
diagnostics until the native host can paint their assets. Legacy compatibility
spellings (`button`, `col`, `input`, `label`, `panel`, `path`, and `row`) are
accepted only through the diagnosed mappings in the machine-readable support
matrix; they are not advertised as current Pulp output. Every unmaterialized
style, layout, attribute, and source field is retained in the node extension
and diagnosed. Bare 64-hex Pulp asset hashes normalize to `sha256:<hex>` and
are verified on import and on an unchanged reimport.

The route fails closed on audio-widget kinds, audio bindings, unknown node or
diagnostic kinds, synthetic multi-selection roots, and unpinned parser/schema
versions. Pulp's name-based extractor can promote names such as `dial`,
`slider`, `level`, or `meter` into audio widgets; until Pulp has an explicit
generic-export mode, such an export is rejected rather than guessed back into a
generic control. It does not decode an arbitrary `.fig`, REST response, or
provider archive. `.pulp.zip` is also not ingested yet: unzip it outside Vellum
and provide `scene.pulp.json` with its sibling `assets/` directory. ZIP magic is
rejected with the stable `source_archive_unsupported` status instead of falling
through to a JSON parse error.

The checked-in
[`pulp-emitter-generic.export.json`](../../fixtures/design-ir/pulp-emitter-generic.export.json)
is generated by Pulp's real `serializeExport` and `AssetCache` implementations.
Its adjacent receipt pins the Pulp commit, exact producer blobs, generator
input, fixture bytes, and asset bytes. Regenerate it with:

```sh
node scripts/generate_pulp_figma_fixture.mjs \
  --pulp-checkout /path/to/pulp \
  --pulp-ref origin/main \
  --esbuild-root /path/to/pulp \
  --input fixtures/design-ir/pulp-emitter-generic.input.json \
  --output-dir fixtures/design-ir
```

The machine-readable route contract is
[`product/source-support.yaml`](../../product/source-support.yaml); unavailable
Claude Design, React-project, HTML, REST, and `.fig` routes are not silently
accepted by the normal CLI.

From an installed local-development CLI:

```sh
vellum create "Import App" --directory ./import-app
cd ./import-app
vellum import ../revision-a.source.json --source-type figma --as main
vellum reimport --source ../revision-b.source.json --as main
```

Both commands support `--json`. The CLI writes deterministic, reviewable files:

```text
sources/imported/main/<revision>/       immutable source and asset snapshot
design/ir/sources/main.designir.json    canonical source DesignIR
design/ir/app.designir.json             active aggregate for the one-source v0
design/generated/                       component definitions and typed IDs
design/overlays/main.authored.json      developer-owned bindings and overrides
design/reports/                         import/reimport diagnostics and candidates
design/import.lock.json                 accepted active revision and hashes
tokens/imported/                        generated primitive tokens
assets/generated/                       copied assets and provenance manifest
ui/generated/                           materialized UI and resolved bindings
src/, components/, native/              developer-owned and never rewritten
```

Edit `design/overlays/main.authored.json` to add bindings, reviewed aliases,
structured visual overrides, semantic tokens, or theme overrides. Reimport
reapplies that file without rewriting it. If a binding or override no longer
resolves, reimport fails, keeps the current DesignIR and lock active, and writes
the candidate DesignIR plus a conflict report for review. Fix the overlay and
rerun the same command. A source snapshot revision can never be replaced with
different bytes.

`cli/tests/test_import_backend.py` executes this public command sequence,
checks deterministic output in different filesystem locations, proves authored
files remain byte-identical, verifies raw Pulp asset hashes (including the
unchanged-reimport path), and exercises the rejected-conflict path.
