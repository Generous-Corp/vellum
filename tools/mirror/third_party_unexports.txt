# Names a mirror image must not export: third-party code and data the mirror
# compiles into its own objects, so a Pulp build that defines the same names
# cannot interpose or coalesce them. ld reads one pattern per line; `*` and `?`
# match. The recipe's third-party archives are listed by
# third_party_unexports.py from the archives themselves, so this file covers
# only what the mirror's own objects define. The installed-dylib census
# (tools/mirror/symbol_census.py --pulp-library) is the check that nothing
# else leaks.
